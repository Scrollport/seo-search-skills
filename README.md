# SEO and search Skills

Agent Skills for turning search evidence into prioritised organic opportunities
and writer-ready content plans, powered by [Scrollport](https://scrollport.com).

## Start with the job

| If you need to... | Use |
| --- | --- |
| Choose the right SEO workflow | [`seo-search`](skills/seo-search/SKILL.md) |
| Compare a site with search competitors and prioritise opportunities | [`seo-opportunity-map`](skills/seo-opportunity-map/SKILL.md) |
| Turn a selected topic into a cited, writer-ready brief | [`seo-content-brief`](skills/seo-content-brief/SKILL.md) |

The router is deliberately thin. Each function Skill has its own trigger,
definition of done, cost ceiling, approval checkpoints and recovery state.
Scrollport supplies the metered tools; the Skill remains free agent-side
instruction.

## Why this package is bounded

- Provider facts, source evidence and agent judgement remain distinct.
- Every paid call is inspected, priced and approved before execution.
- Sampled keyword absence is never presented as proof of a content gap.
- Content publication, site changes and ranking promises are outside these
  Skills.
